# GOLFJAKTEN

Golfjakten är en webbplats för att upptäcka golfbanor i Småland och på Öland. Det är också gjort för att kunna generera golfresor till användare.  
Projektet är skapat inom kursen **(1ME302)** på Linnéuniversitetet.

## Om projektet

Målet med Golfjakten är att göra det enklare för golfspelare att:

- hitta nya golfbanor
- jämföra olika golfbanor
- spara favoritbanor
- planera golfresor

## Kod
Projektet är byggt med:
- HTML
- CSS
- JavaScript
- Leaflet.js
- SMAPI
